# Описание проекта

**Название репозитория:** `powershell-scripts`

**Краткое описание (для поля Description на GitHub):**
Личная коллекция скриптов PowerShell для Windows: анализ и перекодирование видео через FFmpeg.

**Темы (Topics) для GitHub:** `powershell`, `windows`, `ffmpeg`, `video`, `transcoding`, `scripts`, `automation`

## Назначение

Репозиторий хранит рабочие скрипты PowerShell, которые автоматизируют повседневные задачи на Windows. Сейчас в нём два скрипта для работы с видеоархивом; позже коллекция будет разбита на тематические подпапки.

## Состав

- `video_scan.ps1`: инвентаризация видеофайлов (кодек, размер) и оценка выигрыша от перекодирования, отчёт в CSV/XLSX.
- `video_transcode.ps1`: безопасное перекодирование в H.264 / H.265 / AV1 / VP9 с проверкой результата, отчётом и необязательной заменой оригинала (старый файл уходит в Корзину).

## Зависимости

FFmpeg (`ffmpeg`, `ffprobe`); модуль ImportExcel (необязательно, для XLSX); видеокарта NVIDIA (необязательно, для аппаратного кодирования).

## Статус

Ранняя стадия: структура папок не определена, скрипты лежат в корне репозитория.
