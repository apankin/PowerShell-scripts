# PowerShell Scripts

Личная коллекция скриптов PowerShell для Windows. Структура папок будет появляться по мере роста коллекции.

## Скрипты

| Скрипт | Назначение |
|---|---|
| [`video_scan.ps1`](video_scan.ps1) | Сканирует папку с видео (с подпапками) и строит отчёт CSV/XLSX: кодек, размер, приблизительный размер после перекодирования |
| [`video_transcode.ps1`](video_transcode.ps1) | Перекодирует видео в H.264 / H.265 / AV1 / VP9 через FFmpeg, проверяет результат и пишет текстовый отчёт |

Обычный порядок работы: сначала `video_scan.ps1` (понять, что есть и сколько можно сэкономить), затем `video_transcode.ps1` (перекодировать выбранные файлы).

## Требования

- Windows и PowerShell 5.1 или новее
- FFmpeg (должны быть доступны `ffmpeg` и `ffprobe`): `winget install Gyan.FFmpeg`, после установки откройте PowerShell заново
- Для `video_scan.ps1 -Excel`: модуль ImportExcel (`Install-Module ImportExcel -Scope CurrentUser`); без него создаётся только CSV
- Для `video_transcode.ps1 -Encoder gpu`: видеокарта NVIDIA с драйвером (NVENC); кодирование AV1 на видеокарте работает только на RTX 40xx и новее

## video_scan.ps1

Только читает заголовки файлов через `ffprobe`, сами файлы не изменяет.

| Параметр | Описание |
|---|---|
| `-Path` | Папка для сканирования (обязательный) |
| `-TargetCodec` | Необязательно. Целевой кодек для оценки размера: h264, h265/hevc, av1, vp9, vp8, mpeg4, mpeg2, mpeg1, wmv, vc1, prores, dnxhd, mjpeg, theora |
| `-OutDir` | Папка для отчёта (по умолчанию рабочий стол) |
| `-Excel` | Дополнительно создать XLSX |
| `-Delimiter` | Разделитель CSV (по умолчанию `;`, подходит для русского Excel) |

Оценка размера приблизительная (порядка ±30–50%): считается по усреднённым коэффициентам эффективности кодеков.

```powershell
.\video_scan.ps1 -Path 'D:\Video'
.\video_scan.ps1 -Path 'D:\Video' -TargetCodec h265 -Excel
```

## video_transcode.ps1

Звук, субтитры, главы и метаданные копируются без изменений. Результат проверяется (кодек и длительность), и только после этого файл считается готовым.

| Параметр | Описание |
|---|---|
| `-InputPath` | Видеофайл или `.txt` со списком полных путей (по одному в строке, UTF-8; пустые строки и строки с `#` игнорируются) |
| `-Codec` | Целевой кодек: h264, h265 (hevc), av1, vp9 |
| `-Container` | Необязательно: mkv, mp4, m4v, mov, webm. Если не подходит, скрипт сам выберет mkv |
| `-Encoder` | `gpu` (по умолчанию, NVENC) или `cpu` (лучше сжимает, но медленнее) |
| `-Crf` | Необязательно. Качество: меньше значение = лучше качество и больше файл |
| `-Preset` | Необязательно. Пресет скорости кодировщика |
| `-ReplaceOriginal` | Заменить оригинал: старый файл уходит в Корзину. Если результат не меньше оригинала, замены не будет |
| `-ReportPath` | Путь к текстовому отчёту (по умолчанию рабочий стол) |

По умолчанию рядом с оригиналом создаётся новый файл с суффиксом (например, `film_h265.mkv`), оригинал не трогается.

```powershell
.\video_transcode.ps1 -InputPath 'D:\Video\film.mp4' -Codec h265
.\video_transcode.ps1 -InputPath 'D:\list.txt' -Codec h265 -Container mkv -Encoder cpu -Preset slow
```

## Запуск

Если PowerShell не даёт запустить скрипт из-за политики выполнения, разрешите запуск для текущей сессии:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

Справка по любому скрипту: `Get-Help .\video_scan.ps1 -Full`.
